# NEXORA IT Website — Flat Upload Version

All project files are at the same level (no folders), to make uploading from a phone easier.

Files: `index.html`, `main.jsx`, `styles.css`, `package.json`, `vite.config.js`, `.gitignore`, `README.md`.

## Vercel
Import this repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`. Vercel installs dependencies automatically.

## Important
The logo is embedded directly in `main.jsx`, so no image folder is needed. Contact details and sample stats in the design should be replaced with your real company information before publishing.
